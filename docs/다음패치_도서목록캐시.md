# 다음 패치: 도서 목록 캐시와 조회 속도

상태: 기획 보류. 현재 일반도서 UI·UX 작업 후 진행하며 이번에는 구현하지 않음.

- 앱: 언어별 목록을 기기에 저장하고 먼저 표시한 뒤 유효 기간·새로고침에 따라 갱신한다. 실행 중 메모리 캐시와 디스크 캐시를 함께 사용한다.
- 앱: 표지 파일 캐시를 재사용하며 변경된 자산만 다시 받는다. 첫 목록을 표시하기 위해 전체 페이지 조회 완료를 기다리지 않도록 한다.
- 관리자: 독립적인 도서·작품 조회는 병렬화하고, 목록 캐시와 등록·수정·삭제 후 무효화를 함께 설계한다.
- 서버: 공개 회차 수 추가 조회와 페이지 조회 비용을 측정해 개선한다. 공개 변경·예약 발행이 캐시에 뒤늦게 반영되지 않도록 갱신 기준을 정한다.
- 보안: 캐시와 관계없이 다운로드 시 서버에서 현재 공개 여부·버전을 검사한다. 관리자 캐시는 계정별로 격리하고 로그아웃 시 폐기한다.
- 검증: 조회 횟수·첫 표시 시간·재진입 시간을 전후 비교한다. 앱 변경은 iOS·Android 양쪽 검증과 재빌드가 필요하다. 웹·서버 배포는 별도다.
