# 쿠피 사이트 검색 노출 · 다국어 운영 안내

## 이번 구성

기존 홈페이지·앱 소개·이미지 변환 도구는 유지하고, 검색에 필요한 제품 정보와 사용 가이드를 언어별 고정 주소로 제공합니다.

| 내용 | 한국어 | 영어 | 일본어 |
| --- | --- | --- | --- |
| 제품·가이드 안내 | /ko | /en | /ja |
| 쿠피리더 | /ko/koofy-reader | /en/koofy-reader | /ja/koofy-reader |
| 쿠피 이미지 웹 | /ko/koofy-image | /en/koofy-image | /ja/koofy-image |
| TXT·EPUB 읽기 | /ko/guides/read-txt-epub | /en/guides/read-txt-epub | /ja/guides/read-txt-epub |
| HEIC → JPG | /ko/guides/heic-to-jpg | /en/guides/heic-to-jpg | /ja/guides/heic-to-jpg |
| 사진 용량 줄이기 | /ko/guides/reduce-photo-size | /en/guides/reduce-photo-size | /ja/guides/reduce-photo-size |

주소 앞에는 `https://www.koofy.co.kr`가 붙습니다. /ko 등은 기존 홈을 대체하는 자동 리다이렉트가 아니라 제품·가이드 안내 페이지입니다. 메인·제품·푸터에서 연결됩니다.

## 검색 기술 처리

- 18개 페이지 본문을 서버에서 정적 HTML로 생성. JavaScript 실행 없이도 제목·설명·본문·단계·링크를 읽을 수 있습니다.
- 각 페이지에 자기 자신을 가리키는 canonical, 세 언어의 상호 hreflang, 영어 x-default 설정.
- 언어별 제목·설명·Open Graph·공유 정보와 WebPage/TechArticle·BreadcrumbList·앱 정보 구조화 데이터 제공.
- 홈에는 쿠피·쿠피랩·Koofy·Koofy Lab의 WebSite/Organization 정보 제공.
- 기존 robots 검색 허용과 관리자 제외를 유지. 네이버 소유 확인 코드는 변경하지 않음.
- 사이트맵에 새 주소를 추가. 실제 수정과 관계없이 빌드 때마다 변경되던 lastModified는 제거.
- URL에 언어가 있으면 브라우저 언어/이전 선택과 관계없이 해당 언어로 표시. 언어 선택 시 같은 문서의 다른 언어 주소로 이동.
- 일반 공개 페이지의 루트 HTML은 한국어이며 다국어 문서는 article lang과 페이지 본문으로 언어를 명시. 실행 후 문서 언어도 선택 언어로 맞춤.

## 콘텐츠 작성 원칙

실제 지원하는 기능만 씁니다. 웹 변환 도구의 무료·무가입·ZIP 저장을 모바일 앱 정책과 혼동하지 않습니다. 웹 도구 UI는 현재 한국어·영어이며 일본어 문서는 사용 안내입니다. 목표 용량 성공, 무손실 변환, 도서관 대출, PDF 지원을 약속하지 않습니다.

제목과 설명만 바꾸는 복제 페이지나 검색어 반복, 허위 리뷰·별점은 만들지 않습니다. AI 검색도 기본 검색 접근성과 명확한 원문이 우선이며 노출·순위를 보장하지 않습니다. 별도 AI 전용 파일이나 구조화 데이터가 노출 필수 조건이라는 주장은 하지 않습니다.

## 배포 순서 — 소유자 진행

1. Quiz_Site 변경 파일을 확인하고 커밋·푸시합니다. Firebase 및 앱 재빌드는 필요하지 않습니다.
2. Vercel Ready 후 `/ko`, `/en`, `/ja`, `/sitemap.xml`, `/robots.txt` 확인.
3. Google Search Console의 www.koofy.co.kr이 포함된 속성에서 사이트맵 제출 및 홈·대표 제품·가이드 URL 검사 후 색인 요청.
4. 네이버 서치어드바이저에서 사이트맵 제출 및 대표 페이지 수집 요청. 기존 소유 확인이 있는 것과 실제 등록/수집 성공은 다릅니다.
5. 검색 실적에서 쿠피·쿠피랩 및 기능/질문 검색어, 국가별 노출·클릭·색인 상태를 관찰합니다. 직접 검색 결과만으로 색인 여부를 단정하지 않습니다.

Search Console/서치어드바이저 계정 작업과 실제 배포는 이번 코드 패치에 포함하지 않았습니다. 반영 시점과 검색/AI 응답 노출은 외부 서비스가 결정합니다.

## 유지보수 위치

- 번역 원문: `lib/discovery/content.json`
- URL·메타데이터·구조화 데이터: `lib/discovery/index.ts`
- 공통 화면: `components/discovery/DiscoveryPage.tsx`, `discovery.module.css`
- 홈·제품 연결: `components/discovery/DiscoveryLinks.tsx`
- 정적 페이지: `app/[locale]/[[...topic]]/page.tsx`
- 서버 HTML 검증: `python3 scripts/check-search-pages.py http://localhost:3093`

검증 전 `npm run build`, `npm run start -- --port 3093` 실행. 검사기는 18개 본문·대표주소·언어연결·JSON-LD·사이트맵·robots·없는 경로 404를 확인합니다.
