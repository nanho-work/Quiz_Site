# Koofy 대표 사이트 개편 (2026-09-26)

## 목적과 구성

홈은 쿠피 브랜드 소개와 대표 제품 탐색에 집중한다. 앱·게임과 웹사이트 제작 사례를 구분하고, 각 제품에서 설명·이미지·스토어·지원·정책으로 이동한다.

- `/`: 브랜드 소개 → 쿠피리더 → 대표 게임 → 제작 방향 → 문의.
- `/products`: 앱·게임 및 웹사이트 제작 사례 전체 목록.
- `/koofy-reader`: TXT·EPUB 서재, 두 페이지 보기, 독서 설정, 기기 음성 듣기 소개.
- `/products/[slug]`: 기존 제품과 슬라임특공대·허니비, 웹 제작 사례 상세. 정의하지 않은 slug는 404.
- `/about`: 쿠피 소개.
- `/support`: 공통 문의와 쿠피리더 지원 연결. 기존 `/contact`도 이 안내를 제공한다.
- `/policies`: 서비스별 개인정보처리방침과 존재하는 이용약관의 모음.

기존 `/privacy`, `/terms`, `/{app}/privacy`, `/koofy-reader/support`, 관리자, Firebase/API 및 광고 인증 파일은 유지한다. 앱의 동작과 배포 바이너리는 변경하지 않는다.

## 제품 정보와 출시 관리

`lib/marketing.ts`의 `getProducts()`가 메뉴·목록·상세·정책 연결의 제품 정보를 제공한다. 기존 6개 제품의 번역과 스토어 링크는 `lib/i18n.ts`의 제품 데이터를 재사용한다. 새 UI 문구는 한국어·영어·일본어·중국어를 제공한다.

쿠피리더는 현재 iOS 심사 준비 / Android 비공개 테스트로 명시하며 일반 사용자가 설치할 수 있다는 버튼을 표시하지 않는다. 정식 출시를 확인한 후 `copy`의 4개 언어 출시 문구와 `getProducts()`의 링크·상태를 함께 수정한다. 공개 여부를 확인하지 못한 허니비는 소개와 문의·정책만 제공한다. 슬라임특공대는 테스트 상태다.

제품 추가 시 slug, 상세 경로, 이미지, 번역, 출시 상태, 확인한 링크를 등록하고 `productSlugs` 및 sitemap 결과를 점검한다. 쿠피리더는 기존 지원/정책 주소와 나란히 `/koofy-reader`를 사용한다. 존재하지 않는 약관 링크를 만들지 않는다.

## 확인 및 배포

- `npm run build`: 타입 검사, lint, 53개 정적 페이지 생성 통과. 기존 img 최적화 경고 2건은 이번 변경 밖에 남아 있다.
- 로컬 미리보기는 `npm run start -- --hostname 127.0.0.1 --port 3104`.
- 데스크톱 홈, 390px 모바일 홈·리더·제품 메뉴, 320px 제품 목록을 브라우저에서 확인했다. 한국어·영어·일본어·중국어 전환 시 가로 넘침이 없음을 확인했다.
- 새 제품/지원/정책 및 기존 법적 문서·관리자 로그인·ads.txt·app-ads.txt·sitemap의 27개 경로가 HTTP 200, 알 수 없는 제품 경로는 404임을 확인했다. 관리자 로그인 후 기능과 실제 스토어 설치는 이번 검증 범위에 포함하지 않았다.
- 실서비스 배포·git 커밋·푸시는 이 패치에서 수행하지 않았다.
- 되돌릴 때는 이번 공개 웹 변경만 되돌린다. 기존 법적 문서의 Remote Config 갱신과 관리자 변경은 포함하지 않는다.
